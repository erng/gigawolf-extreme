# Archived bodyguard sprites

19 alternative 16x16 bodyguard designs drafted for the game (numbers match the original pick list; #14 became the shipped sprite in `js/ui/pixel.js`).

- `options.json` — `{ id, name, pal, grid }` per sprite, same format as `SPRITES` in `js/ui/pixel.js` (`.` = transparent, letters index `pal`).
- `preview.html` — open in a browser to view them all.
